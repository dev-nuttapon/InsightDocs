## Winning Demo Focus

InsightDocs ต้องขายเพียง 3 เรื่อง:

1. Governed PDF lifecycle
2. Approval-to-signature workflow
3. End-to-end traceability

ดังนั้นหน้าเดโมที่ต้อง polish ระดับประกวดมีเพียง:

1. Dashboard
2. Document Detail
3. Approvals
4. Signatures
5. Audit

หน้าที่เหลือเป็น supporting screens และไม่ควรขยาย scope ก่อน flagship flow จะเสร็จ
