# Frontend Guidelines — InsightDocs

## 🎯 Goal

Ensure UI consistency, scalability, and professional appearance across the application.

---

## 🧱 Layout Rules

Every page must have:

- PageHeader (title + subtitle + actions)
- Content section inside a consistent container
- Proper spacing (no cramped UI)

---

## 🎨 Styling Rules

- Use CSS variables only (no hardcoded colors)
- Support light/dark theme
- Use consistent spacing (8px grid)
- Use border + subtle shadow (avoid heavy UI)

---

## 🧩 Component Rules

Always reuse components when possible:

- PageHeader
- SectionCard
- StatCard
- StatusBadge
- EmptyState
- FilterBar

---

## 📊 Tables

- Must have proper spacing
- Must have hover state
- Must have empty state
- Must not overflow

---

## 🏷️ Status

Use StatusBadge for:

- Draft
- In Review
- Approved
- Rejected
- Signed

---

## 🧠 UX Rules

- No blank pages
- No broken buttons
- Always show loading or empty state
- Actions must be obvious

---

## ❌ Forbidden

- Hardcoded colors
- Inline styles (unless necessary)
- Duplicate UI patterns
- Inconsistent spacing
